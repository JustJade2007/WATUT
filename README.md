# WATUT (What Are They Up To) - Fabric Port

Port of WATUT to Minecraft 26.3 on Fabric.

## Requirements
- Minecraft 26.3
- Java 25+
- Fabric Loader >= 0.20.1
- Fabric API
- CoroUtil (26.3-1.3.8+)
- Forge Config API Port (Fabric 26.3+)

## Building
Run `./gradlew build` (using `build_fabric.gradle` as `build.gradle`). Built jar will be placed in `build/libs/`.
